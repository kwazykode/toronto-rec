# Toronto Rec Tracker

Mobile attendance and pass-cost tracker for adult 19+ pickleball, badminton,
and volleyball at Canoe Landing and One Yonge.

[Open tracker](https://kwazykode.github.io/toronto-rec/)

## Features

- 110 sessions from July 20–August 23, 2026
- Centre, sport, week, access, and attendance filters
- $159.80 pass analysis with a $4.96 per-session target
- Device-local attendance storage
- City schedule links and verified access labels

Schedule data was retrieved July 31, 2026. July 20–26 repeats the published
weekly pattern. Confirm current details before attending.

## Development

Open `index.html`; no build or dependencies are required. Add recurring weeks
to `WEEKS`; counts and filters update automatically.

The deployed page requests exclusion from search results but remains accessible
to anyone with its URL.
